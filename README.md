# Агатэк — сайт (вариант 1 «Подбор»)

Рабочий сайт: гаражные ковры, антибукса и фиксаторы. Astro + three.js, без сервера.
Публикация: https://stellasdeutsch-dev.github.io/agatek/ (GitHub Actions при пуше в main).

- `npm run dev` — разработка, `npm run build` — сборка в `dist/`.
- Товары, цены, артикулы: `src/data/products.ts` (со старого сайта агатэк.рф, ноябрь 2026).
- 3D-сцены: `src/scripts/three-scenes.ts` (гараж с машиной, гаражные ковры, антибукса). Грузятся только когда видны, при «уменьшить движение» — без анимации.
- Корзина хранится в браузере, заказ и формы открывают письмо на agatek@bk.ru.
